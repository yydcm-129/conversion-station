把一切小说资料，搬进墨韵

转换空间站是墨韵（Moyun）小说工作台的配套转换器：酒馆角色卡、RP-Hub 聊天记录、成品小说 TXT/EPUB、老版 RP-Hub 小说数据……凡是墨韵之外的格式，都由它转换成墨韵可以直接导入的书籍 JSON / TXT / EPUB，然后放进墨韵继续创作。

立即使用（浏览器直接打开） 查看源码与文档
● 全程本地处理，正文不上传 零依赖 · 单文件 HTML Windows / macOS / 手机浏览器通用 5 条测试链 + 8 个端到端探针

为什么需要它

墨韵专注创作本身，而你的素材散落在各种生态里：酒馆的角色卡是 JSON/PNG，RP-Hub 的聊天记录是 JSONL，下载站精校小说是 TXT/EPUB，老版本的旧书还躺在旧数据里。转换空间站只做一件事——把这些格式变成墨韵认识的样子，让"搬书"这一步不丢数据、不费手工。

🎭角色卡 → 小说设定

支持 SillyTavern V1/V2/V3、TavernAI、RP-Hub、RisuAI、Agnai 的 JSON 与 PNG 卡（含世界书上千条目），自动分类筛选后整理为墨韵角色设定与剧情大纲。

正向转换 · 可选 AI 精修

📖聊天记录 → 小说

导入 RP-Hub 分支聊天导出，自动剥离思维链、状态栏与 UI 数值块，按回合整理成章节材料，交给你的 AI 写成墨韵格式小说。

长文分批 · 系统楼层

📚成品小说 → 可编辑小说

TXT / EPUB / 墨韵 JSON 一键导入，智能切分章节、识别书名作者与卷结构，兼容知轩藏书等精校下载站的文件形态，AI 精读只提取既有设定、绝不改写正文。

导出 JSON / TXT / EPUB

↩️小说设定 → 角色卡

反向通道：把墨韵书籍 JSON/TXT 还原为七种主流酒馆卡格式，支持 PNG 角色卡封装与独立 UI 包缓存。

七种格式 · 双向回读

🖋️文风样本 → 文风指南

借鉴墨韵文风蒸馏方案，把小说正文或聊天 AI 楼层蒸馏成防复述的写作风格指南（Markdown），可直接粘贴进墨韵"文风设置"。

40 字防复述校验

📦老版小说 → 新版迁移

老版 RP-Hub「小说生成」的书库 JSON / 导出 TXT，逐本转换为新版墨韵书籍 JSON——补齐章节必需字段，保留摘要与书评，老版密钥数据绝不带出。

三步上手

导入素材

拖入文件，或直接粘贴文本。放错区块会自动识别文件类型并询问是否跳转。

检查与转换

本地整理或调用你自己的 AI 接口精修；进度分步可见，随时可停。

导入墨韵

导出墨韵 JSON / TXT / EPUB，在墨韵「导入 JSON」中选入即可继续创作。

🔒 隐私与安全边界

所有解析与转换都在你的浏览器里完成；只有当你主动点击生成类按钮时，对应的预览材料才会发送到你自己配置的 AI 接口。API Key 默认只保存在页面内存中，保存接口设置也不会写入密钥；老版书库里的 globalSettings（含密钥）在迁移时整树丢弃。角色卡 UI 预览运行在无脚本、无网络的沙箱里。
